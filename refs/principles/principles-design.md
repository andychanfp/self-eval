## How to apply

When cross-checking a project record against these principles:

1. Read the description of work done.
2. For each principle, ask: does the record contain a specific action or decision that fits the "Self-eval signal"?
3. List only principles where the match is concrete — a general claim ("I care about users") does not count.
4. Present the matched principles to the user before drafting.
